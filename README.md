# الملفات الدراسية · مُستدرِك
Study files for the AI faculty class of 2030, Delta University · A Mustadrak project

**الموقع:** https://nooh-ibrahim.github.io/mustadrik-study/

## الموقع ده إيه
الملفات الدراسية لدفعة 2030 (كلية الذكاء الاصطناعي، جامعة الدلتا) في لينك واحد ثابت. فرع من مُستدرِك.
- بيشتغل **من غير نت** بعد أول فتحة، ويتضاف للشاشة الرئيسية كأنه تطبيق.
- ملفات المواد مش هنا: على سيرفر `mustadrak-stats` ومقفولة بالتصريح (`c.html` بيفتحها، و `pdf.js` بينزّل الطباعة). بترفعها `study/build/tools/site-sync.mjs`.

## الصفحات
| الصفحة | فيها إيه | الـ JS |
|---|---|---|
| `index.html` | الرئيسية: الختم، وكارت الاسم، وكارت لكل مادة، والحساب على أكتر من جهاز | `home.js` و `me.js` |
| `m.html?s=<الملف>` | صفحة المادة: الفتح، وملفات الطباعة، والملاعب بصورها، والمحاضرات، وطريقة الشرح | `course.js` |
| `account.html` | حسابك: الاسم والرقم، والتقدّم، والوقت، والجلسات، والغلطات، والأجهزة (من `POST /me`) | `account.js` و `mytime.js` |
| `key.html` | دليل الرموز: كل رمز في المواد بصورته الحقيقية ومعناه | (ثابتة) |
| `guide.html` و `guide.pdf` | شرح الموقع في 3 صفحات (`?print` للـ PDF) | |
| `c.html` | بيفتح ملف المادة من السيرفر ويحفظه | |

ومشترك: `site.css`، و `ui.js` (الوضع الفاتح والغامق، والـ Service Worker، والاسم في الشريط اللي فوق)، و `stats.js` (العدّاد)، و `acct.js` (التصريح والمزامنة)، و `pdf.js`.
**الشريط اللي فوق (`<nav class="top topnav">`) متكرر في الأربع صفحات**: أي تعديل فيه يتعمل في الأربعة.

## البيانات والصور (الأدوات في `tools/`)
- `node tools/course-data.mjs [--shots]`: بيفتح ملفات المواد المبنية (من `study/build/<المادة>/config.json`) بكروم من غير واجهة، ويكتب `data/courses.json` (المحاضرات والدروس والملاعب وعدد الأسئلة). مع `--shots` بيصوّر كل ملعب فاتح وغامق في `img/labs/`. **شغّلها بعد رفع مادة فيها دروس أو ملاعب جديدة.** الكلام المكتوب بإيد لكل ملعب في `tools/labs-text.mjs`.
- `node tools/key-shots.mjs`: صور «دليل الرموز» في `img/key/`. شغّلها لو شكل حاجة في المحرّك اتغيّر.
- `node tools/seal.mjs <الترم> <الامتحانات اللي خلصت>`: الختم بحلقة التقدّم (`icons/seal.svg`). دلوقتي `1 0`.
- `tools/cdp.mjs`: كروم والسيرفر المحلي للأداتين الأولانيين.

## إزاي يتحدّث
1. عدّل، وجرّب (الصفحات محتاجة سيرفر بيفتح `/` وبيعرف نوع SVG، زي GitHub Pages).
2. زوّد `VERSION` بواحد في `sw.js`، وزوّد «إصدار الموقع» و `hub-version` في `index.html`.
3. ارفع على `main` **بعد موافقة نوح**، والموقع بيتحدّث لوحده في دقيقة أو اتنين.

الصفحات والـ JS والـ CSS والـ JSON بتتجاب من النت الأول، فالتحديث بيوصل أول ما الطالب يفتح بالنت، ومن غير نت بيفتح آخر نسخة اتحفظت. الصور والخطوط من المحفوظ الأول.
**ماتغيّرش أسماء ملفات المواد**: اللينكات اللي الطلبة حافظينها هتبوظ.
